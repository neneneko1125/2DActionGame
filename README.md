タイトル：SwordFriend  
ジャンル：2Dアクションゲーム  
制作目的：自動で判断して動くNPCキャラクターを作るため  
苦労した点：スマートフォンで遊べるように対応したこと　自身のチャンネルのショート動画で紹介したため、スマホで気軽に遊べたほうがいいだろうと判断したため、スマホにも対応させました

バージョン：6000.3.10f1  
使用言語：C#
